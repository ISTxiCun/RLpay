# 该项目为单体模块化项目
## 该项目地址：https://github.com/ISTxiCun/RLmall

## 项目要实现什么？
- 该项目要实现“面向商城的聚合支付网关”+“渠道账单对账与差异处理”
- 灵感来源于jeepay（https://github.com/jeequan/jeepay）

## 目前暂定的技术栈为：
- jdk 17、springboot 3.5.9、MySQL 8.0.44、Maven 3.9.9、MyBatis-Plus、Redis 8.2、Flyway
